# tinkersbin

Personal electronics parts inventory for hobbyists. Capture parts via phone camera, identify them through a vision-language model, enrich from the original vendor's product page, track them across multiple purchase lots, and never re-order something you already have on the bench.

See `.context/project.md` for the full project description, `.context/decisions/` for architectural decisions, and `CLAUDE.md` for the Code Bridge protocol used to coordinate between Claude Web Chat (architect) and Claude Code (builder).
